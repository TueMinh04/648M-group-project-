6. How We Used Generative AI (Claude & Gemini)

A transparent disclosure of AI assistance, failure modes caught, and human verification.

Academic Integrity & Transparency Statement: Generative AI tools (Claude and Gemini) were used strictly as an assistive aid for frontend layout scaffolding, code syntax structuring, analyzing procedure video into 2D simulation images, and editorial polishing. Following health professions AI governance[12] and our core principle—"AI assists; humans remain accountable"—all clinical guidelines, research syntheses, ethical arguments, and simulation scoring rules were 100% human-authored and verified by our student team.

Project Area & Tools What AI Helped With What Went Wrong (Risks Caught) How We Checked & Fixed It
Website & Prototype
Claude Gemini
  • Helped build the responsive layout and CSS styling for the website.
  • Set up browser session saving so user progress is remembered between steps.
  • Suggested heavy third-party software packages that we didn't need for a simple static site.
  • Suggested using live AI to score students, which was slow and gave unpredictable feedback.
  • Kept the code lightweight and simple using standard HTML, CSS, and JavaScript.
  • Replaced live AI scoring with fixed, clear rules so feedback is always accurate and reliable.
Video & 2D Images
Gemini
  • Analyzed procedure videos and generated 2D anatomical images for the interactive simulation.
  • Generated blurry images, distorted anatomical boundaries, and awkward instrument angles.
  • Hand-checked and filtered every 2D image against real medical anatomical charts before using it in the demo.
Clinical Questions & Data
Claude
  • Turned hospital procedural checklists into quiz questions, multiple-choice options, and explanations.
  • Made up wrong measurements (like tube insertion depth landmarks) and gave incorrect catheter sizes.
  • Audited every single question, landmark, and number directly against official hospital policies (Scarborough Health Network and Humber River Health).
Ethics & Research
Claude Gemini
  • Brainstormed initial ethical topics (patient consent, data privacy, user fatigue).
  • Gave vague buzzwords ("ensure fairness", "protect data") without legal backing and hallucinated fake journal citations.
  • Threw out the fake citations and independently searched academic databases to find real, peer-reviewed medical studies and clinical guidelines.
Writing & Tone
Claude
  • Proofread draft paragraphs for clarity, active voice, and smoother flow.
  • Kept using the clinical word "hallucinations" and exaggerated marketing hype ("revolutionizes medicine overnight").
  • Changed "hallucinations" to "AI misinformation", and toned down hype so it clearly reads as an academic student prototype.
