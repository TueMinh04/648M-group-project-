# Contributing
- Branch names: `page/ethics`, `feature/scoring`, `fix/nav-mobile`.
- Keep commits small; message format: `area: what changed` (e.g. `ethics: add consent evidence`).
- Open a pull request to `main`; at least one teammate reviews. No direct pushes to `main`.
- Edit content in `assets/js/data/` where possible; avoid touching layout CSS unless needed.
- Do not add sources, statistics or clinical claims you have not verified. Cite everything.
- Log any generative AI use in `docs/ai-usage-log.md`.
- Check keyboard navigation and mobile width before merging.
